# 经纬 GRAVITY · 全球地缘决策沙盘

纯前端中文研究应用，React 19 + Tailwind CSS 4 + Leaflet + Vite。无后台、无 API 密钥、无用户数据上传。

- 在线：https://grot666.github.io/geopolitical-sandbox/
- 源码：https://github.com/grot666/geopolitical-sandbox

## 本地运行

使用 Node.js 22.12+（已在 Node 24 测试）。

```sh
npm ci
npm run dev
# 打开 http://localhost:5173/geopolitical-sandbox/
npm test
npm run build
npm run preview
```

可选无头交互测试：`npx playwright install chromium` 后 `npm run test:e2e`。配置优先使用 `CHROME_PATH` 指定的 Chrome；否则使用 Playwright 下载的 Chromium。截图保存在 `test-results/`，不提交仓库。

## 功能

### V3「一眼洞察」升级（2026-11-18）

- **一眼看穿当前世界**：页首摘要由 `events.json` 与当前权重自动生成（现行危机列表、结构性风险最高的未爆点、综合第一），每个名称可点击打开档案；切换权重即时变化。
- **第一名主卡**：一句话本质、地理宿命、核心筹码；其余 Top 2–5 以紧凑卡片呈现。
- **区域快速切换**：全球总览 / 中东双海峡 / 东欧大平原 / 第一岛链·台海 / 美洲与加勒比；按区域边界自适应缩放（手机上同样完整显示区域）。
- **大感应半径**：每个焦点下方有 26px 透明感应圈，悬停即在地图右上角显示速览卡，点击打开档案。
- **双语国家标注**（中文 + English，可关闭）与**战略大区水印**（放大后显示、让位于国家名）。
- **能源 / 芯片 / 矿产走廊**：`corridors.json` 5 条示意走廊，每条均附来源与日期（见下文核实情况），标签参与标注避让。
- **派系投射驾驶舱**：美欧各 4 类政治力量（`factions.json`）。悬停/键盘聚焦预览、点击固定；在地图上从起点画出到相关热点的投射弧线与“倾向”标签（屏幕空间避让，不互相遮挡），其余节点变暗；一键重置；可折叠（手机默认折叠）。档案第 4 节列出指向该热点的派系倾向并可一键投射。
- **档案第 5 节「多方底层生存焦虑对撞」**：对称呈现各方焦虑与目标；“目标”尽量引用公开表态，其余标为分析重构。档案顶部显示当前排名。
- **权重弹窗预设**：紧迫度 45/25/20/10、结构 10/40/25/25、等权 25/25/25/25。
- **可选底图**：默认始终是本地矢量（离线、中文标注、零第三方请求）；可手动切换到 OpenStreetMap 标准瓦片（显示 © OpenStreetMap contributors 署名）。连续加载失败自动切回本地并提示；选择不持久化，每次打开都恢复本地。
- **线状要素可悬停**：航线、能源/芯片/矿产走廊、地形与分界线、同盟连线、派系投射弧线都有透明加宽感应带（鼠标 18px、触屏 26px），位于节点之下、线条之上；悬停时线条加粗发光并在光标旁显示速览（名称、类型、承载内容/意义、来源与日期），点击固定说明卡；重叠处点击会列出附近全部线路供切换；侧栏“地图线路索引”支持键盘与触屏。经纬网、国家轮廓为纯装饰，不可交互。
- **AI 情报扩展（本地注入）**：复制提示词 → 在你自己的 AI 工具中生成 → 粘贴 JSON → 严格校验后仅在本浏览器显示。详见“注入安全”。

- 自动 Top 5、紧迫度 / 结构影响双权重、四维自定义权重实验。
- 地图点位尺寸与置顶顺序随得分变化；现行危机红色脉冲、潜伏点琥珀静态光环、资源通道青绿色。
- 全球与区域 FlyTo、本地战略地形示意与海峡、战略资源、精选同盟网络、贸易路径开关。
- 所有主焦点、资源、海峡均可点击，查看四维依据与 What / Geography / Resources / Politics 四段分析。
- 美国行政/两院/党内路线/产业及外交倡议组织，欧盟机构/成员国分歧/英国/土耳其制度面板。
- 观察清单检索、状态筛选、研究 JSON 导出、来源档案、移动端布局、键盘关闭与焦点约束、减少动画偏好。
- 中文国家/地区名称：177 个，来自 Natural Earth `NAME_ZH`（公共领域）并人工校订为常用简称（如“中国”“朝鲜”“韩国”）；标注点使用 Natural Earth `LABEL_X/LABEL_Y` 内部点，而非多边形质心。按缩放分级显示：全球视图显示主要国家，下钻后显示更多国家及海、海峡、运河名称；贪心碰撞避让，避开危机标记与图例，标签不拦截点击、位于标记下层。争议地区（台湾、西撒哈拉、科索沃、巴勒斯坦、北塞浦路斯、索马里兰、福克兰群岛/马尔维纳斯）使用中性地理名称，悬停有说明，不构成主权认定。替换轮廓后运行 `python3 scripts/build-labels.py` 重新生成。
- 无第三方地图依赖：同源加载本地轮廓；轮廓失败时提示并保留研究点位和全部分析数据。首次打开网页本身仍需要网络；不是完整 PWA 离线缓存。

## 评分与认识论

`G = round(Σ(score_i × weight_i) / Σ(weight_i), 1)`，各维 0–100。全零和非法权重拒绝；同分稳定按 ID 排列。

| 模式 | 烈度 | 系统外溢 | 大国/核升级 | 地理杠杆 |
|---|---:|---:|---:|---:|
| 紧迫度 | 45 | 25 | 20 | 10 |
| 结构影响 | 10 | 40 | 25 | 25 |

尺寸 `12 + G × 0.25` 像素；置顶 `round(G × 10)`。原始评分、权重与状态互相独立：改变权重不改变事实、状态或四维评分。资源和咽喉详情明确提示其继承关联地区评分，不应误解为单个厂区的安全评估。

“Objective”指公开规则与可复算，不表示没有价值判断。四维分数、证据信心、因果链均为分析师估计，不能当作实测物理量、战争概率、道德排名、投资建议或政策效果预测。缺乏同口径数据时，系统外溢依据定性锚点，不伪造全球份额。维度存在相关性，不能用小数精度暗示统计精度。

## 地图与许可

默认地图**完全本地渲染，不加载任何第三方瓦片**：Natural Earth 国家轮廓（`public/world.geojson`）、经纬网、本地 `src/data/terrain.json`（山脉屏障、平原走廊、海峡与岛链示意线）及咽喉节点。

底图选择经过逐一实测（下载瓦片并查看图像与响应头）：

| 提供商 | 实测 | 结论 |
|---|---|---|
| OpenStreetMap 标准瓦片 | 正常渲染、无水印 | **作为可选项**。遵守 [OSMF 瓦片政策](https://operations.osmfoundation.org/policies/tiles/)：仅人类交互浏览、显示署名、浏览器默认 Referer、无预取/离线/批量下载；默认关闭，失败自动回退本地。自动化测试中 OSM 请求被本地桩替换，不访问其服务器。 |
| CARTO 暗色瓦片 | HTTP 200 但图像带“API KEY REQUIRED”水印 | 不提供 |
| Esri（暗灰、影像、晕渲等） | 图像正常 | 不提供：Esri 条款要求使用 Esri 软件或 ArcGIS 订阅/密钥，本项目不满足 |

项目不使用 Esri/ArcGIS、CARTO、Mapbox、MapTiler、Stadia、Thunderforest、Google 等需要密钥或订阅的服务（单元测试会扫描源码确认）。若本地轮廓加载失败，界面提示，研究点位、航线与分析仍可使用。

本地轮廓来自 [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)（公共领域），下载自 nvkelso/natural-earth-vector 的 ne_110m_admin_0_countries.geojson。轮廓仅为低分辨率研究参照；边界、点位、首都连接与航线不构成主权主张、势力范围、基地位置、当前部署或法律承诺。欧盟机构点位不表示欧盟整体是北约成员；图中相应关系仅表示跨大西洋成员合作。

应用原创代码采用 MIT；第三方统计、报道与地图版权归各权利人，链接不代表背书。

## 注入安全（AI 情报扩展）

- 页面**不调用任何 AI 或网络接口**，也没有后端或密钥；提示词由你复制到自己的工具中使用。
- 只接受 `JSON.parse` 能解析的对象或数组；**从不执行**粘贴内容（无 `eval`/`Function`/`innerHTML`），所有文本经 React 按纯文本渲染，地图标签另行 HTML 转义。
- 严格模式：只允许规定字段（含嵌套对象，原型链键如 `__proto__` 也会被拒），类型、长度、id 格式、状态枚举、坐标范围、0–100 整数评分、`YYYY-MM-DD` 日期、仅 `https://` 且不含账号的来源链接、≤4 个视角、≤8 条来源、≤30000 字符、本机最多 12 个节点。
- 注入节点 id 自动加 `user-` 前缀，**不能覆盖或替换已核实节点**；地图上为紫色虚线标记，档案与清单标注“用户注入·未核实”，默认不参与 Top 5 与摘要（可手动开启）。
- 仅保存在本浏览器 `localStorage`；每次加载都会重新校验，被篡改的数据会被丢弃；“清除全部注入”一键删除。

## 参考稿中刻意未采用的内容

- 未核实或过时的数字：霍尔木兹“39 公里”、马六甲“2.8 公里”、红海“12% / 30%”、南美锂“58%”、稀土“85%”、民调百分比、“130–150 美元”油价冲击预测。改用 EIA、USGS、IEA 的带日期数据；“台湾 92% 先进产能”仅以 SIA/BCG 2021 报告（2019 年产能、10nm 以下）的历史基线形式出现。

- 参考稿的弱校验注入器（仅检查 id/坐标/评分）及“注入即替换核实数据”的做法。

## GitHub Pages 部署

Vite `base` 为 `/geopolitical-sandbox/`。工作流每次推送 main 自动安装依赖、执行单元/数据测试、构建、上传 Pages artifact 并部署；无需单独 gh-pages 分支。

由已获授权的 GitHub CLI 首次配置：

```sh
gh repo create grot666/geopolitical-sandbox --public --source=. --remote=origin
# 创建站点（若已存在不重复执行）
gh api --method POST repos/grot666/geopolitical-sandbox/pages -f build_type=workflow
git push -u origin main
gh run list --repo grot666/geopolitical-sandbox
```

在 GitHub 设置中 Pages 来源应为 **GitHub Actions**。修改仓库名需同步 `vite.config.js` 的 base。静态根路由不使用 History Router，刷新无需服务端路由规则。官方依据：[Custom workflows with Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

### 评分校准
- **动能烈度**：以已有节点为锚点。乌克兰 96（高强度国家间战争）、伊朗 72、红海 58。苏丹战争有多条战线和无人机围城，给 88；仅有封锁或围困、尚未确认国家间全面战争的埃塞—厄立特里亚给 70；城市帮派或犯罪暴力在 30–55 之间；没有武装冲突的政治与宪政危机（波黑、塞尔维亚、埃塞奎博）在 15 以下。
- **系统外溢**：参照马六甲 93、巴拿马 66。只有涉及关键航道、矿产或大规模难民的地区冲突才给到 55–65。
- **大国介入**：只有美国直接军事行动（委内瑞拉 80）或北约 / 欧盟驻军与调停（科索沃 62）高于 55；以地区国家介入为主的冲突在 25–55 之间。
- **结果**：现行 Top 5 的计算逻辑没有改动。苏丹以 70.1 进入第五，把朝鲜半岛（57.5）挤到第九，这是如实打分的结果。低分的局部冲突只在筛选或放大后才会显眼。
- **防拥挤**：综合分低于 45 的节点圆点更小（`markerSize`）。缩放级别低于 3 时，综合分低于 50 的节点隐藏分数角标和脉冲环；缩放低于 2.5 时，被标记遮住大半的小国名称不再强行显示。
